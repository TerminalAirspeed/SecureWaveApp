# SecureWave

**Proprietary Android communications application — Public Beta**

> **Release preparation in progress.** The beta.5-r15 (version code 491) release is being checked for public testing. It has **not yet been published to this repository**. Do not install older beta builds as though they are the latest version.

SecureWave provides local authenticated encrypted text, encrypted file storage and exchange, verified contact pairing, and encrypted digital messaging using compatible radio/audio equipment. **Open Radio is deliberately unencrypted.** SecureWave does not request the Android `INTERNET` permission; external applications used to transport encrypted payloads have their own privacy and metadata practices.

## Distribution and licensing

- This repository is a **public APK distribution location**, not the source repository.
- The SecureWave source remains **proprietary and private**; no source-code license is granted here.
- Limited-beta testing terms and copyright attribution are being finalized before the next release.
- A GitHub public pre-release will be prepared only after the signed APK, test results, checksums, documentation, and licensing notices have been approved.

## Safety notices

- SecureWave has **not** been independently security-audited or certified. Do not use beta builds as your only emergency communication method or for sensitive operational information.
- Do not use Secure Radio encryption on services where it is forbidden. Encrypted transmissions intended to obscure meaning generally are not permitted on US amateur-radio frequencies or GMRS.
- Do not uninstall an existing SecureWave installation just to upgrade; doing so may destroy local encryption keys and data.
- Files released by GitHub are publicly downloadable even when the application itself is proprietary.
