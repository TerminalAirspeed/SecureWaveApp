# SecureWave

**Proprietary Android communications application — Public Beta**

The beta.5-r15 (version code 491) release is being checked for public testing. 
SecureWave provides local authenticated encrypted text, encrypted file storage and exchange, verified contact pairing, and encrypted digital messaging using compatible radio/audio equipment. **Open Radio is deliberately unencrypted.** SecureWave does not request the Android `INTERNET` permission; external applications used to transport encrypted payloads have their own privacy and metadata practices.

## Distribution and licensing

- This repository is a source repository.

## Safety notices

- SecureWave has **not** been independently security-audited or certified. Do not use beta builds as your only emergency communication method or for sensitive operational information.
- Do not use Secure Radio encryption on services where it is forbidden. Encrypted transmissions intended to obscure meaning generally are not permitted on US amateur-radio frequencies or GMRS.

## Developer feedback

Please use GitHub Issues for non-sensitive bug reports. Do **not** post private messages, contacts, encryption keys, credentials, or unredacted sensitive logs.
